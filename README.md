# Практическая работа № 1 — тестирование складского остатка

Небольшое учебное решение на C#, показывающее, как изолированно проверять правила предметной области с помощью MSTest. В качестве примера выбран складской остаток: товар можно принять или списать, но его количество не должно становиться отрицательным.

## Цель и результат

Цель работы — выделить проверяемую логику в библиотеку классов и покрыть ключевые сценарии модульными тестами. Решение не зависит от пользовательского интерфейса, базы данных или внешнего сервиса: тесты напрямую создают объект `StockItem` и проверяют его состояние после операций.

## Что реализовано

- создание товара с названием и начальным остатком;
- очистка пробелов по краям названия;
- приём только положительного количества;
- списание только положительного количества;
- запрет списания сверх доступного остатка;
- проверка переполнения `int` при увеличении остатка;
- проверка ошибочных аргументов и сохранения состояния после отказа операции.

### Класс `StockItem`

Класс хранит неизменяемое имя товара и текущее количество. Методы `Add` и `Remove` выполняют проверки до изменения состояния. Неположительное количество отклоняется исключением `ArgumentOutOfRangeException`; недостаточный остаток — `InvalidOperationException`. Для сложения используется `checked`, поэтому переполнение не приводит к незаметному искажению количества.

### Набор тестов

Тесты сгруппированы по поведению объекта: корректная инициализация, успешный приём, успешное списание, недопустимые количества, попытка списания сверх остатка, пустое название и отрицательное начальное значение. В сценариях отказа дополнительно проверяется, что количество товара осталось прежним. Для значений приёма используется `DataTestMethod`, чтобы одним тестом проверить несколько недопустимых входных данных.

## Требования

- Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений .NET» либо .NET SDK 8;
- Windows 10/11 для Visual Studio; библиотеку и тестовый проект можно запускать на любой системе с совместимым .NET 8 SDK.

## Сборка и запуск тестов

Откройте `PracticalWork1.sln` в Visual Studio и выполните **Тест → Запустить все тесты**. В командной строке из каталога репозитория:

```powershell
dotnet test StockControl.Tests/StockControl.Tests.csproj
```

Для обычной сборки решения:

```powershell
dotnet build PracticalWork1.sln
```
